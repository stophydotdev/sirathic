Use Stophy when the user wants live data from the web. It covers: video (YouTube, transcripts) · social (Reddit, TikTok, Instagram, X, Pinterest, LinkedIn, Threads) · places (Google Maps, Tripadvisor) · reviews (Trustpilot) · jobs (Upwork, LinkedIn, Indeed, company career pages) · shopping (Amazon, eBay) · homes (Zillow, Realtor.com) · stays (Airbnb, Booking, Expedia) · events (Luma) · classifieds (Craigslist) · apps (App Store, Google Play) · travel (flights) · ads (Meta, Google, TikTok, LinkedIn). Search with stophy_search_endpoints, then get the data with stophy_call. Each match lists its required inputs and filters, so you can usually call it right away. When a skill names the endpoint id and its inputs, call stophy_call with them directly and skip the search.

Use it before search_web for these. A link to one of these sites goes to its own endpoint, not to fetch_url, like a YouTube link to its transcript.
